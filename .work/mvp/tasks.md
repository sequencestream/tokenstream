# Tokenstream MVP 阶段原子任务

依据：[架构](../../doc/architecture.md)、[MVP 规格](../../doc/mvp/mvp.md)、[MVP 设计](../../doc/mvp/design.md)、[编码设计](./coding-design.md)。架构中的透明性、安全、路由与头部规则优先；本清单仅拆分 MVP 已确定的工作，不新增产品能力。

## 执行约定

- 按阶段推进；同阶段中无依赖的任务可并行。每项以可观察的结果和对应验证为完成标准，不能仅以实现已提交代替验收。
- `依赖` 为任务编号；`—` 表示可直接开始。任务编号稳定，完成时将 `[ ]` 改为 `[x]`。
- 每个阶段结束时运行已适用的测试。最终须通过单元、双数据库仓储、HTTP/WebSocket 契约、安全、负载和固定客户端兼容性七层验证。
- 管理面与数据面保持独立认证和路由；代理不解析应用载荷，不生成客户端回退请求，也不加入重试、协议转换、限流或缓存。

## 阶段 0：工程与静态约束

- [x] **T00-01 建立工程骨架**｜依赖：—｜交付：Rust 异步服务、测试入口和最小 Vue 3 管理应用可分别构建；开发与生产运行方式明确。验收：干净环境中构建和基础检查通过。
- [x] **T00-02 加载并校验启动配置**｜依赖：T00-01｜交付：监听地址、数据库地址、加密主密钥、管理员密码哈希、连接与头部及空闲超时、连接数、HTTP 缓冲、WebSocket 大小和队列、日志容量与批量参数在监听前校验；密钥只从环境秘密或秘密管理渠道获取。验收：缺失或越界配置导致安全且无敏感值的启动失败。
- [x] **T00-03 建立双平面入口与生命周期**｜依赖：T00-01、T00-02｜交付：数据面和管理面使用独立路由树及认证中间件；启动前运行迁移，关闭时停止接收新连接并按配置限定排空时间。验收：两种凭证不能跨平面使用，关闭过程有确定上界。
- [x] **T00-04 定义无秘密领域边界**｜依赖：T00-01｜交付：提供者、凭证、请求日志、内部请求标识、不可变请求快照和带秘密保护的值具有独立表示；数据库自增 ID 与请求标识分离。验收：ID 和游标拒绝非正值；秘密值不能被调试输出或序列化，管理响应只有独立的脱敏表示。

## 阶段 1：持久化和密码材料

- [x] **T01-01 实现 SQLite 版本化迁移**｜依赖：T00-04｜交付：两张表、自增且删除后不复用的正整数主键、唯一性/枚举/外键限制、查询索引；每条连接启用外键约束。验收：迁移可重复执行，删除被日志引用的提供者失败。
- [ ] **T01-02 实现 PostgreSQL 等价迁移**｜依赖：T00-04｜交付：等价的自增 64 位主键、外键、唯一性、检查约束和索引；数据库差异留在存储适配层。验收：与 SQLite 一致的约束测试通过。
- [ ] **T01-03 实现提供者存储契约**｜依赖：T01-01、T01-02｜交付：按密钥 ID 查找、创建、更新、限制删除和按 ID 游标列表；写入由数据库生成 ID，错误归一化。验收：两种数据库均通过单调 ID、删除后不复用、唯一性、事务回滚和数值游标顺序测试。
- [ ] **T01-04 实现请求日志存储契约**｜依赖：T01-01、T01-02｜交付：起始写入、按唯一请求 ID 幂等完成、按正数 ID 游标和固定过滤条件查询；开始事件缺失时完成事件不补行。验收：两种数据库均通过外键、幂等、空结束时间、筛选和事务测试。
- [ ] **T01-05 统一存储时间与连接池**｜依赖：T01-03、T01-04｜交付：存储层使用有符号 UTC 微秒时间戳，边界转换为 UTC 时间；由数据库地址选择后端，连接池有显式上界。验收：双数据库时间往返一致，池耗尽时认证请求安全失败。
- [ ] **T01-06 实现上游密钥加解密**｜依赖：T00-04｜交付：AES-256-GCM 密文同时携带随机 nonce、密钥版本和密文，主密钥不入库。验收：往返、nonce 唯一性、篡改拒绝、错误不泄密测试通过。
- [ ] **T01-07 实现网关凭证签发与验证**｜依赖：T00-04｜交付：随机非秘密密钥 ID 和至少 256 位熵的秘密组成凭证；只持久化 Argon2id 哈希，验证避免依秘密值变化的比较路径。验收：格式/长度边界、正确与错误哈希、只展示一次的测试通过。

## 阶段 2：提供者服务、认证与请求判定

- [ ] **T02-01 实现提供者创建服务**｜依赖：T01-03、T01-06、T01-07｜交付：校验名称、协议、状态、端点与上游密钥；默认仅允许 HTTPS，非 HTTPS 只在显式开发模式；加密、哈希和完整记录在单事务中写入。验收：成功时仅返回一次新网关凭证，失败时没有半成品或秘密回显。
- [ ] **T02-02 实现提供者编辑、停用与删除**｜依赖：T02-01｜交付：配置编辑原子提交；停用阻止新请求；仅未被日志引用的提供者可删除，否则给出 `409 provider_in_use`。验收：已建立连接仍使用原快照，新请求观察提交后的配置。
- [ ] **T02-03 实现网关凭证轮换**｜依赖：T02-01｜交付：在一个原子操作中更新密钥 ID 与哈希，只返回一次新凭证。验收：提交后旧凭证对新请求失效，已建立连接不中断。
- [ ] **T02-04 实现数据面凭证解析和快照加载**｜依赖：T01-05、T01-06、T01-07、T02-01｜交付：按提供者原生头部提取受长度限制的凭证，按密钥 ID 直查数据库，验证启用状态并解密，形成单请求不可变快照；不使用应用级凭证缓存。验收：缺失、重复、冲突、错误、禁用凭证均在上游接触前失败且不泄密。
- [ ] **T02-05 实现 OpenAI 固定路由与升级判定**｜依赖：T02-04｜交付：仅允许 OpenAI `POST /v1/chat/completions`、`POST /v1/responses` 和 WebSocket 升级 `GET /v1/responses`；按规范化路径和标准升级头判定，不读取正文。验收：OpenAI 的错误方法、无效升级、其他路径及 Anthropic 路径均在上游接触前拒绝。
- [ ] **T02-06 实现目标地址拼接**｜依赖：T02-01、T02-05、T02-09｜交付：端点 origin 和可选基础路径前缀与已验证路径安全拼接，原查询串原样转发且不记录。验收：前缀保留、路径穿越拒绝、特殊查询字节不被改写。
- [ ] **T02-07 实现双向头部规则**｜依赖：T02-04、T02-05、T02-09｜交付：去除固定及 `Connection` 指名的逐跳头、`Proxy-Authorization` 和不可信转发链；按直接下游对端建立单值转发信息，替换原生凭证，设置上游 authority，保留其他端到端头；响应去除逐跳头。验收：重复/冲突凭证被拒，版本及 beta 头保留，秘密不进入错误或日志。
- [ ] **T02-08 实现本地错误契约**｜依赖：T02-05、T02-09｜交付：稳定的错误码、HTTP 状态、内部请求 ID 和脱敏消息；上游已有响应时保持其状态与正文。验收：认证、停用、路由、升级、连接、超时、容量和内部故障的分类正确；恶意上游文本不进入本地错误。
- [ ] **T02-09 实现 Anthropic 固定路由与传输判定**｜依赖：T02-04｜交付：仅允许 Anthropic HTTP `POST /v1/messages`；按规范化路径判定，不读取正文或据此推断 SSE。验收：Anthropic 的错误方法、WebSocket 升级、其他路径及 OpenAI 路径均在上游接触前拒绝。

## 阶段 3：HTTP 与 SSE 透明代理

- [ ] **T03-01 实现全局准入与资源上界**｜依赖：T00-02、T02-08｜交付：全局信号量限制已准入代理连接，HTTP 缓冲和各排队点有边界；容量满时返回 `503` 并释放资源。验收：并发超过上界时无无界排队，退出路径不泄漏许可。
- [ ] **T03-02 实现 HTTP 请求流转发**｜依赖：T02-06、T02-07、T03-01｜交付：请求正文以有背压的有界流发送；连接与响应头超时生效；不解析、修改或完整缓存应用正文。验收：任意分块、未知字段、大正文及慢上游均保持字节序列并受界限约束。
- [ ] **T03-03 实现 HTTP 响应与 SSE 流转发**｜依赖：T03-02｜交付：收到上游响应头后即转发状态和允许的头，正文分块直接传递；不依据内容类型或 `stream` 字段改变行为。验收：跨块 SSE 事件、上游错误正文、任意分块和慢下游保持透明且有背压。
- [ ] **T03-04 实现 HTTP 取消与故障收束**｜依赖：T03-03｜交付：下游取消终止关联上游工作；EOF、空闲超时和异常释放许可；响应头前用本地错误，流已开始则终止流；不重试。验收：取消、突断、超时场景无残留任务或重复请求。
- [ ] **T03-05 验证三条 HTTP 路线**｜依赖：T03-04｜交付：Chat Completions、Responses 和 Messages 的普通与 SSE 契约测试，覆盖请求/响应字节、查询串、认证替换和上游错误。验收：所有路线通过可控模拟上游测试。

## 阶段 4：Responses WebSocket 代理

- [ ] **T04-01 实现双端握手顺序**｜依赖：T02-06、T02-07、T03-01｜交付：仅在上游升级成功后接受下游升级；重建必要升级头，不翻译子协议或扩展。验收：握手失败仍为普通 HTTP 响应，上游拒绝的状态/正文保持原样，无上游响应时给脱敏本地错误。
- [ ] **T04-02 实现双向消息与关闭中继**｜依赖：T04-01｜交付：文本、二进制和控制消息按所选库边界双向转发；任一侧关闭或失败时尽可能传递关闭状态并取消对侧，不重连。验收：同时流量、分片消息、ping/pong、关闭码和突断契约测试通过。
- [ ] **T04-03 实现 WebSocket 容量与慢端处理**｜依赖：T04-02｜交付：消息、帧、出站队列与空闲等待都有配置上界，超大消息按明确策略关闭并记录脱敏错误。验收：慢消费者和越界输入保持稳定内存且不会累积任务。
- [ ] **T04-04 验证客户端拥有的回退流程**｜依赖：T03-05、T04-03｜交付：可控客户端在 WebSocket 失败后自行发送独立 HTTP/SSE 请求；网关仅分别处理两次请求。验收：HTTP 回退流透明，独立请求 ID 和日志记录，无网关协议转换。

## 阶段 5：非阻塞日志与可观测性

- [ ] **T05-01 实现有界非阻塞事件发送**｜依赖：T01-04｜交付：开始和完成事件只尝试入队；满队或关闭时立即丢弃并增加丢弃计数，绝不阻塞代理。验收：队列饱和仍完成代理请求，内存受界限约束。
- [ ] **T05-02 实现后台批量写入**｜依赖：T05-01｜交付：按大小或短周期批量落库；数据库失败仅在工作线程内有限重试，操作日志限速；请求线程不等待写入。验收：失败和恢复期间代理结果不变，完成事件按请求 ID 幂等。
- [ ] **T05-03 接入 HTTP 与 WebSocket 生命周期日志**｜依赖：T03-04、T04-03、T05-02｜交付：HTTP 记录上游状态和结束时间；WebSocket 记录握手状态与关闭时间；路径不含查询串，错误摘要经脱敏。验收：握手失败、关闭后客户端回退、事件丢失和进程重启后未完成记录均如实呈现为“不完整”。
- [ ] **T05-04 接入安全聚合指标**｜依赖：T03-04、T04-03、T05-01｜交付：活跃 HTTP、活跃 WebSocket、上游延迟、安全类别的代理失败、日志队列深度和丢弃事件指标。验收：无密钥 ID、查询串或其他高基数秘密标签。
- [ ] **T05-05 完成有界优雅关闭**｜依赖：T00-03、T05-02｜交付：停止准入、按配置排空活动请求，再给日志独立的有界刷新窗口。验收：超时后进程可退出，不合成未完成日志的结束时间。

## 阶段 6：管理 API 与页面

- [ ] **T06-01 实现管理员会话**｜依赖：T00-03、T01-07｜交付：单管理员密码验证、短时 `HttpOnly`/`Secure`/`SameSite` 会话、查询和注销接口，变更接口执行 CSRF 校验。验收：未授权、跨站请求、过期和注销后访问被拒；响应不回显密码。
- [ ] **T06-02 实现提供者管理接口**｜依赖：T02-01、T02-02、T02-03、T06-01｜交付：创建、读取、按正整数 ID 游标列出、编辑、停用、限制删除和凭证轮换；接口只返回脱敏配置，凭证只在创建或轮换响应中出现。验收：限制删除返回 `409`，列表默认 100 且最大 100，无 offset/页码/总页数。
- [ ] **T06-03 实现请求日志查询接口**｜依赖：T01-04、T06-01｜交付：支持 `after_id`、`limit`、提供者、传输类型及起始时间区间过滤；ID 升序及末条游标，空页游标为 `null`。验收：非法游标与过大页长被拒，过滤保持固定时翻页稳定，未完成记录可辨识。
- [ ] **T06-04 实现管理页面**｜依赖：T06-02、T06-03｜交付：登录、提供者列表与增改停删、一次性凭证展示与轮换、请求日志筛选及加载更多；页面对未完成记录使用“不完整”状态。验收：端到端操作成功，刷新后不再展示旧凭证，页面不接收密文或哈希。

## 阶段 7：安全、负载与兼容性发布门禁

- [ ] **T07-01 完成安全回归**｜依赖：T05-03、T06-04｜交付：扫描 API 响应、日志、指标与错误在恶意头部、查询串、上游文本和正文下的泄漏；验证停用/轮换/跨提供者拒绝及认证失败关闭。验收：无密钥、哈希、密文、正文或查询秘密外泄，非法请求不上游。
- [ ] **T07-02 固定并执行并发负载画像**｜依赖：T05-04、T05-05｜交付：记录并执行包含长连接 HTTP/SSE 与 WebSocket 的并发画像、持续时间和内存判据。验收：内存趋稳，全局连接、数据库池、HTTP 缓冲、WebSocket 队列和日志队列均未越界。
- [ ] **T07-03 固定客户端版本清单与模拟上游**｜依赖：T03-05、T04-04｜交付：版本控制内固定 Codex CLI、OpenAI SDK、Anthropic SDK 的精确版本，并提供可控模拟上游；外部服务不作为 CI 正确性依赖。验收：每个客户端的支持路线和回退场景可重复执行。
- [ ] **T07-04 运行完整发布门禁**｜依赖：T01-05、T03-05、T04-04、T07-01、T07-02、T07-03｜交付：单元、SQLite/PostgreSQL 仓储、HTTP/WebSocket 契约、安全、负载和固定客户端兼容性结果。验收：全部通过；任一失败都不能标记 MVP 完成。
